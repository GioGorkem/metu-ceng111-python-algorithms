# METU CENG 111 — Python Algorithms & Problem Solving

Algorithmic problem sets, recursive combinatorial solvers, and computational thinking projects developed in Python for **CENG 111: Introduction to Computer Engineering Concepts** at Middle East Technical University (METU / ODTÜ).

Developed by [Görkem Akbulut](https://github.com/GioGorkem) (METU Computer Engineering).

---

## Portfolio Modules

* **`01_core_algorithms/`**: String manipulation algorithms, custom delimiter splitting, mathematical geometry calculations, and character matrix transformations.
* **`02_python2_to_python3_transpiler/`**: AST and text-transformation functions designed to systematically parse and convert legacy Python 2 syntax into idiomatic Python 3.
* **`03_pathfinding_and_stack/`**: Custom LIFO stack data structures and grid-traversal pathfinders (Frodo Mordor traversal and Titan 3D multi-level protocol).
* **`04_grid_tiling_and_backtracking/`**: Combinatorial polyomino/tetromino grid-tiling solver using recursive backtracking, state pruning, and autonomous drone deployment heuristics.
* **`05_blockchain_simulation/`**: Educational blockchain simulation demonstrating cryptographic hash chaining, proof validation, and tamper-evident transaction ledgers.

---

## Technical Highlights
* **Paradigms:** Functional programming, recursive backtracking, modular decomposition.
* **Algorithmic Efficiency:** Optimized state space search and recursive pruning techniques.
* **Language:** Modern Python 3 standard library with zero external dependencies.
